# HDDE｜最低必要验证路由

选择与改动直接相关的验证，不默认执行全量发布审核。

## 1. 仅前端文件

最低候选：

- 相关 lint 或静态检查；
- `npm.cmd run build`；
- 真实页面加载；
- 本阶段关键按钮、状态、导航和错误提示；
- 控制台新增错误检查；
- `git diff --check`。

不要自动运行图片处理全回归，除非改动影响处理合同。

## 2. 仅 Python 后端

最低候选：

- 修改文件 `py_compile`；
- 直接相关单元或集成测试；
- 真实服务或目标函数调用；
- 必要 API 请求；
- 错误路径验证；
- `git diff --check`。

## 3. 前后端合同

最低候选：

- 后端直接相关测试；
- 前端构建；
- 真实 API；
- 真实页面状态；
- 错误状态；
- 字段与用户可见结果一致；
- `git diff --check`。

## 4. 正式目录

最低候选：

- 配置读取；
- 路径规范化；
- 可写性检查；
- 正式写入；
- 不可用目录失败阻断；
- 不回退 tmp/runtime_data；
- 不改写设置；
- 重启后状态；
- 前端真实显示；
- `git diff --check`。

## 5. 历史迁移和清理

最低候选：

- 只读目录盘点；
- 数据归属分类；
- 冲突预检；
- 迁移前后文件清单；
- 可读性或完整性抽查；
- 不确定数据保留；
- 安全清理验证；
- 正式目录结构；
- 受保护工作区复查；
- `git diff --check`。

## 6. 图片处理

最低候选：

- 固定代表性真实图片；
- 原图哈希或存在性保护；
- 输出完整解码；
- 尺寸和比例；
- 格式与 Alpha；
- 关键中文、Logo、人物、产品结构检查；
- 输出路径；
- 错误输入；
- 直接相关测试；
- `git diff --check`。

## 7. 日志

最低候选：

- 触发真实启动、配置、目录、处理或写入事件；
- 检查等级；
- 检查阶段、原因、影响和定位信息；
- 检查无噪声重复；
- 检查敏感信息；
- `git diff --check`。

## 8. 版本和品牌

最低候选：

- 权威版本源；
- 前端显示；
- 后端接口；
- 系统设置；
- 构建信息；
- 相关测试；
- 用户可见品牌字符串扫描；
- `git diff --check`。

## 9. 何时扩大验证

仅当以下任一成立：

- 修改跨越关键架构层；
- 数据迁移不可逆；
- 影响原图或正式文件；
- 修改公共数据合同；
- 影响多个核心页面；
- 存在重大兼容风险；
- 当前任务卡明确要求。

扩大验证时仍不得建设无用户价值的复杂测量器。
