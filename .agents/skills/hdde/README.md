# HDDE Codex Skill

- 内部名称：`hdde`
- 显示名称：`HDDE`
- 调用方式：`$hdde`
- 类型：仓库级、显式调用、instruction-only
- 当前版本：`1.1.0`

## 定位

用于执行已经定义清楚的影界 HDDE 单阶段开发任务。

它负责：

- 真实仓库基线读取；
- 未提交和冻结成果保护；
- 根因定位；
- 最低必要实现；
- 真实运行；
- 直接相关验证；
- 阶段报告；
- 通过并冻结或真实架构阻断。

它不负责：

- 产品规划；
- 下一版本优先级；
- 模糊需求探索；
- 多阶段路线图；
- 自动提交、推送或发布。

## 推荐安装位置

将整个 `hdde` 文件夹放入：

`.agents/skills/hdde`

调用：

`$hdde`

默认关闭隐式调用，避免在高风险仓库任务中误触发。

## 使用前

1. 使用 `assets/task-card-template.md` 由 ChatGPT 撰写当前阶段任务卡。
2. 在 Codex 中显式调用 `$hdde`。
3. 执行后将最终报告交回 ChatGPT 审核。
