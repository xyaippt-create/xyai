# HDDE｜阶段任务生成检查表

由 ChatGPT 在撰写任务卡前检查。

## 必须明确

- 当前最值得解决的唯一问题；
- 项目、分支和预期 HEAD；
- 已确认问题与真实证据；
- 不可破坏边界与 Git 权限；
- 5—8 个面向结果的验收门禁；
- 六项简短报告合同；
- 普通任务卡 400—800 字，复杂任务原则上不超过 1200 字。

## 不应进入任务卡

- 重复的长期执行纪律；
- 大量历史聊天；
- 已经写入 Skill 的 Git 禁止规则；
- 多个版本的混合目标；
- 模糊的“顺便优化”；
- 无法验证的愿望性目标；
- 与当前阶段无关的未来规划。
- 写死必须修改的文件、组件结构、变量名称或逐步实现过程；
- 与当前改动无关的大量测试细节。

## 放行条件

只有在任务可以用一句话回答以下问题时才交给 `$hdde`：

“本阶段只解决什么，并用什么真实结果证明完成？”
