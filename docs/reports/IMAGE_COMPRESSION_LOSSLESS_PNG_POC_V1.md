# 影界图片压缩 PoC v1｜PNG 同格式真正无损验证报告

## 1. 任务定义

影界图片压缩 PoC v1 的目标是保持 PNG 格式、像素尺寸、解码像素、Alpha 和关键元数据不变，只通过真正无损的编码结构优化降低文件体积。

以下内容不属于本任务：

- 视觉无损；
- JPG95；
- WebP 或 AVIF；
- 格式转换；
- 图片尺寸缩小；
- 锐化、降噪、调色或增强。

## 3. 技术路线

处理前先验证 PNG 签名、完整块结构和 CRC，并确认 `IHDR`、`IDAT`、`IEND` 结构有效。优化过程只解压并重新压缩 `IDAT` 中的 zlib 数据，不重建像素，不改变解压后的过滤扫描线字节。

所有非 `IDAT` 块的类型、内容和相对顺序必须逐字节保持，包括 ICC、DPI、EXIF、XMP、文本块、调色板、透明信息和未知辅助块。候选必须通过格式、尺寸、色彩类型、位深、隔行、像素、Alpha、元数据、完整解码和原图哈希等全部硬门禁；只有候选文件严格小于原图时才保留，否则删除候选并保持原图。

## 6. 元数据保持结果

- ICC：`iCCP` 原始块保持，解码 ICC 内容哈希一致；
- DPI：`pHYs` 内容一致，原图与候选解码值一致；
- EXIF：Orientation 均为 `6`，`eXIf` 内容及解码 EXIF 哈希一致；
- XMP：`iTXt` 内容哈希一致；
- `PLTE`、`tRNS` 及所有其他非 `IDAT` 块均逐字节保持，类型、内容和相对顺序一致。

最终证据中的像素、Alpha、过滤扫描线、元数据和块比较结果均为一致。

## 7. 拒绝与回退结果

- APNG 通过 `acTL`、`fcTL`、`fdAT` 结构准确识别并拒绝，状态为“不支持处理”，未生成 APNG 候选；
- CRC 损坏文件在 `IDAT` CRC 校验阶段准确拒绝；
- 带未知关键块 `ABCD` 的文件准确拒绝；
- 已高度优化的 67 字节静态 PNG 产生的候选仍为 67 字节，候选被删除并保持原图；
- 任何候选只要没有变小或反而变大，均不得采用。

## 8. 最终技术结论

> PNG同格式、像素级真正无损压缩 PoC：PASS。

结论限制：

- 当前只证明静态 PNG 路线；
- APNG 不支持；
- JPEG 系数级无损压缩仍为 BLOCKED；
- 不承诺固定压缩比例；
- 已高度优化的 PNG 可能没有进一步收益；
- 当前尚未接入正式 UI、API 或 pipeline；
- 本报告不代表正式产品功能已经上线。

## 9. 产品边界

- PNG 无损压缩：保持格式、像素尺寸和解码像素不变，只优化编码结构；
- 缩小图片尺寸：属于后续独立 PoC，会改变像素尺寸，不能与本路线混为一谈；
- 格式转换：不属于本任务，后续根据明确需求另行决定；
- JPEG：不得使用 JPG95、质量参数重新编码或高相似度指标冒充真正无损；只有可靠的系数域工具经过验证后，才能重新评估。
