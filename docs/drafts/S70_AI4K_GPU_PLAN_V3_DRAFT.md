## 1. 现状

### FACT

- **4K v4 已冻结**（11-13，负责人“认可，冻结 v4”）。模型 `realesr-animevideov3-x3`，走 `realesrgan-ncnn-vulkan`，整张 6.4–8.6 秒。合同 `4k_v1_contract_2.1`。
- **v4 的融合已经包含第二版四层保护里的三层的雏形**：
  - 反投影只锁低频明暗，色度取原图放大；
  - 超分对中频的改动受原图局部结构幅度限制（不许凭空画线），肤色降权；
  - 极小字不用超分，只用原图放大后锐化。
  - 没有的是：防白边钳制（以原图邻域为参照）、文字按字号分级。
- **11-13 换模型对比**（5 张图）：x4plus、animevideov3-x3、x4plus-anime 套上同一套融合后，清晰度相差 ≤0.1，目视难分。v4 对 LANCZOS 的屏幕观看清晰度是 1.20–1.42 倍。
- **11-13 加强档**（9 张图）：把融合强度调高，清晰度再高 2–9%，但人脸出现睫毛和眼线描边，头发变硬、发际出现亮边。未采用。
- **x4plus 原始输出**会画出原图没有的发丝和笔触纹理（S70-A 复查裁切 `checks/t1_p1_portrait_maxblock_src_vs_x4.png`）。
- **S70-A 速度**：本机只有 Intel Iris Xe 集成显卡。x4plus 约 39 秒/百万像素；1.2–1.6 MP 的图 48–67 秒，3.41 MP 的图 130 秒，超过 120 秒预算。冷热启动相差不到 1 秒。

- **许可**：代码和程序 CLEARED；x4plus 权重 UNKNOWN；训练数据 NOT_CLEARED（DIV2K 仅限学术研究）。

### INFERENCE

- 清晰度的上限由“融合放多少模型细节进来”决定，不由模型决定。放得多，人脸和头发先出问题。
- 所以 x4plus 换不来 R1。能换来 R1 的是：先把白边、亮边、伪纹理挡住，再把融合强度放开。这正是第二版 ① ② 两层的作用，但它们应该加在 v4 上。
- 用快模型调参，每张 7 秒左右；用 x4plus 每张 1–2 分钟。同样的调参轮数，前者快一个数量级。

## 3. S70-1 v4 差距盲评

**唯一目标**：用负责人的眼睛确认，已冻结的 v4 在 R1、R2 上各差多少。

**做什么**
1. 负责人提供盲评集（见第 7 节），放到 `D:\HDDE样本` 下单独的文件夹。
2. 每张出 LANCZOS 和 v4 两版，随机排序、不标来源。用正式 v4 代码在隔离根目录产出，不写 `D:\影界文件`。

4. 标杆人像单独看：v4 成品上，标杆的四处瑕疵还剩几处。

**出口**
- 正常观看 ≥8/10 更好、0 更差，且 100% 检查 0 例 → v4 已达标，S70 到此结束。
- R1 不够（“一样”偏多）→ S70-2 的目标是放开强度。

## 4. S70-2 保护层 PoC

**开工前的硬门禁**
- 未提交文件已备份。
- 负责人已对许可风险表态。
- S70-1 有结论，知道要解决的是 R1、R2 还是两者。

**唯一目标**：在 v4 融合上补齐保护层，使融合强度可以放开而不出瑕疵。

### 4.1 管线

```
输入
 → 预检：格式、尺寸、ICC、位深、透明通道
 → 尺寸路由（见 4.2）
 → 超分（先用现用的 animevideov3-x3）
 → 缩放到长边 3840
 → ① 防白边钳制
 → ② 伪纹理检测 + 局部降混合
 → ③ 反投影锁定（沿用 v4：只锁低频，色度取原图）
 → ④ 文字/Logo 分级保护
 → 羽化合成
 → 补回 ICC、透明通道
 → 最终一致性复核
 → 输出 + 每张一份质检记录
```

顺序说明：①② 会改像素，所以放在反投影之前。锁定之后只做文字替换，最后再量一次一致性。

### 4.2 尺寸路由

| 情况 | 处理 |
|---|---|
| 不需要放大（长边 ≥ 3840） | 跳过，不增强 |
| 放大倍数很小（临界值用样本定，初始按 1.5 倍以下试） | 只做传统放大 |
| 中等（到模型倍数为止） | 超分一次，然后缩到 3840 |
| 超过模型倍数 | 超分一次，剩下用 LANCZOS 补齐，标注“原图过小，细节上限低” |
| **仅 x4plus：原图超过约 3 百万像素** | 不走 x4plus，改走快模型或传统放大 |

不对小图跑两次超分。像素量上限按 S70-A 的 39 秒/百万像素和 120 秒预算算出，换机器或改预算要重算。

### 4.3 四层各自管什么

| 层 | 解决的瑕疵 | 做法 | 和 v4 的关系 |
|---|---|---|---|
| ① 防白边钳制 | 小字白边、发丝亮边 | 每个像素限制在**原图对应位置邻域**的最亮和最暗之间，加小容差。参照用原图，不用 LANCZOS 结果 | 新增 |
| ② 伪纹理检测 | 毛衣平行细线、皮肤条纹、凭空的发丝 | 原图里没有对应结构却多出规则细线的地方，降低模型混合比例 | 加强 v4 已有的结构幅度约束 |
| ③ 反投影锁定 | 颜色、构图漂移 | 沿用 v4 | 不改 |
| ④ 文字/Logo 分级 | 笔画变形、白边 | **小字**：换回原图放大像素，边缘羽化。**大字和标题**：保留模型结果，靠 ① 防白边。字号分界线在调参集上定，记录依据。Logo 按小字处理 | v4 只有“极小字”一级，改为分级 |

①② 到位后，再逐步放开中频强度，看人脸和头发在哪个强度开始出问题。11-13 加强档的参数是现成的起点。

### 4.4 量化指标（每张都记，辅助人工，不代替人工）

- 下采样一致性：成品缩回原尺寸和原图的差，不差于 v4。
- 清晰度增益：对 LANCZOS 的屏幕观看清晰度比，和 v4 逐张对比。
- 白边溢出：钳制前后超出原图邻域范围的像素占比，钳制后接近 0。
- 伪纹理命中：② 标记的区域数量、面积和截图。
- 文字漏检：调参集的文字区域人工标注一次，漏掉的小字区域必须是 0 处。
- ICC、位深、透明通道：和输入一致。

### 4.5 验收门禁

- 上面的指标全部达标。
- 屏幕观看清晰度高于直接放大（LANCZOS），目视不差于 v4，且 Claude 自查的人脸、头发、小字无新增瑕疵。
  - 口径变更（负责人 2026-11-15 回复“改，继续做”）：原文是“屏幕观看清晰度高于 v4”。原因：S70-1 和 S70-2 的实测显示 v4 的清晰度指标有一部分来自亮边和伪纹理，挡掉后指标必然下降；按原口径，去掉瑕疵反而算不通过。
- 完整管线复测速度：热启动单张 ≤ 预算，按像素量分档报告。
- 四层分别开关的消融对比齐全。

- 负责人 2026-11-15 回复“进 S70-3 盲评”：S70-2 第二轮没达标的几项（调参集小字漏检 1 处、白边溢出 0.16–1.97% 未到接近 0、16 位输入输出为 8 位、水壶类宽光晕未解决）记为已知项，带入 S70-3，不再补一轮。S70-2 的参数冻结在 `artifacts/s70b_quality_pipeline/final_params_v2.json`。

调参只用调参集。产物放 `artifacts/s70b_quality_pipeline/`，不改正式代码。

**停止条件**：放开强度后人脸或头发的瑕疵挡不住，同一层最多再调一轮。还不行就停，报告“保真融合下清晰度到顶”，由负责人决定接受 v4 还是进 S70-E。
