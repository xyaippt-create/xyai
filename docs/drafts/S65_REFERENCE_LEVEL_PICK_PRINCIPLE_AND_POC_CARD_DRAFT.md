## 第一部分｜原则补充：参考图挑档校色

### 1. 为什么要改

2026-10-28 对现有参考图校色做了只读扫描，共 10 组测试，其中 8 组用"同一张图偏色前的干净原图"做参考，也就是有标准答案：

- 5 组直接保留原图，另外 5 组改动肉眼看不出（整图色差 0.2–0.6）；
- 离正确颜色最多只近了约 4%，有两组反而更远；
- 8/10 组被判定为"缺少共同中性色锚点"，颜色匹配因此被关闭。剩下能放行的组，又被 45% 的强度、多重修正上限和较弱的基础执行器层层削弱。

结论：现有参考图校色对 AI 图基本不起作用。

### 2. 新原则

1. **参考图只提供两样东西**：
   - "白应该是什么白"，即参考图在各亮度段的中性色色偏；
   - 可选的整体明暗风格。

   不搬运参考图的具体颜色和内容，不做风格迁移。
2. **修正方法**：把目标图在各亮度段的中性色色偏，向参考图对应亮度段的色偏移动。复用 S64 已冻结的分亮度色适应、肤色保护、柔和收顶与收底；中性色用 S64 的稳健估计，不再依赖原 D1 的"中性色证据充分"判定。
3. **用户挑档**：输出"原图 / 轻 / 中 / 强"四档，用户选定才生成正式结果。系统只提示，不替用户决定，与 S64 一致。
4. **安全**：
   - 尺寸、Alpha 不变；
   - 裁切增量 ≤ 0.5%；
   - 肤色色相偏移 ≤ 10°；
   - 高饱和品牌色区域的颜色变化单独量化列出。
5. **适用范围**：本原则只作用于"参考图挑档校色"这一新路径。现有参考图校色在正式集成前保持不变；集成时是替换还是并存，由负责人另行决定。

### 2. 本阶段唯一目标

在隔离实验中证明：以参考图的分亮度中性色为目标的"参考图挑档校色"，能把偏色目标图明显拉向参考图的色调，三档强度递增，并且不伤图。同时与现有参考图校色做对照。

### 3. 已确认问题

- **用户影响**：参考图校色对 AI 图几乎无效。
- **证据**：2026-10-28 的扫描结果，见第一部分第 1 节。
- **未确认事项**：
  - 参考图与目标图内容差异很大时，分亮度中性色还是否可比；
  - 明暗风格匹配对 AI 图是增益还是风险。

### 4. 不可破坏边界

- **正式代码一律不改**：正式颜色链、参考图校色、挑档校色、页面、API、Settings、正式目录、版本号。
- **只新增**：`tools/experiments/` 下的执行器，以及 `artifacts/s65_refcolor_poc/` 下的输出。所有输出写在仓库 artifacts 内，不写用户输出目录或 `D:\影界文件`。
- **样本**：
  - 复用 `D:\HDDE样本\AI4K` 与 `AIColor`，只读，记录 SHA；
  - 负责人另外提供的真实"目标图 + 参考图"配对，放在 `D:\HDDE样本\RefColor`；如果没有提供，本项记为未验证。
- **禁止**：Git 写操作、联网、生成模型、Mock、伪成功。

### 5. 结果门禁

1. **有标准答案的测试组**：从至少 6 张干净的 AI 图出发，各加偏黄、偏蓝、偏绿/品红三种色偏作为目标图，用干净原图作参考。
   - "强"档到标准答案的平均 ΔE00 比目标图缩小 ≥ 60%；
   - "中"档缩小 ≥ 40%；
   - 三档单调递增。
   - 这些数值是初始建议，由 PoC 校准，执行方不得自行放宽。
2. **同系列参考**：至少 3 组"偏色目标图 + 同系列另一张干净图"作参考。
   - 结果到目标图干净原图的 ΔE00 缩小 ≥ 40%（中档）；
   - 同时报告与现有参考图校色的对照。
3. **不误改**：参考图就是目标图本身时，各档变化 ΔE00 ≤ 0.5；目标图与参考图色调已经一致时，"中"档 ΔE00 ≤ 1.5。
4. **安全**：
   - 全部档位裁切增量 ≤ 0.5%；
   - 可信人脸色相偏移 ≤ 10°；
   - 尺寸与 Alpha 不变；
   - 高饱和区域色差单独列出。
5. **性能**：约 2K 的图，四档预览合计 ≤ 5 秒。
6. **对照**：所有测试组都用现有正式参考图校色跑一遍，把两者到标准答案的距离并列对比。
7. **复核包**：逐组四档对比图（目标图 / 参考图 / 轻 / 中 / 强），附 `HUMAN_REVIEW.md` 打分表。

价值成立标准（负责人确认后冻结）：
- 门禁 1–4 通过；
- 在同系列与真实配对中，人工复核认为"有一档比现有参考图校色明显更好、可直接使用"的比例 ≥ 75%；
- 没有任何伤害。
