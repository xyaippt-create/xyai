## 第一部分｜《参考图校色：白 + 明暗 + 饱和度对齐》原则变更稿

### 1. 变更原因

负责人 2026-10-29 实测：用展厅照片作目标图、白花图作参考图，校色后与参考图不像。

测量（强档）：

| | 白色调 a\*, b\* | 平均亮度 L\* | 平均饱和度 C\* |
|---|---|---|---|
| 原图 | 2.0, 6.0 | 48 | 13.8 |
| 强档 | −4.3, 9.7 | 48 | 15.7 |
| 参考图 | −3.6, 12.9 | 79 | 25.3 |

现行 S65、S66 方法只对齐"白"，明暗和饱和度原样保留。负责人要求的"更接近参考图"，需要把这两项也对齐。

旧的 `reference-run` 也曾对齐曝光、对比度和饱和度，但限制过于保守，几乎从不生效（见 S67 扫描）。

### 2. 新原则

1. **对齐三项，只对齐这三项**：
   - **白**：沿用 S66 的方法，不改变。
   - **明暗**：整体亮度和对比度，用 L\* 的中位数、5% 分位、95% 分位来衡量。
   - **饱和度**：整体饱和程度，用 C\* 的中位数和 90% 分位来衡量。
   
   不搬运色相和配色：画面里是红色的东西仍然是红色，不会因为参考图是绿的而变绿。也不做局部调色、滤镜或风格化。
2. **分档**：轻、中、强分别补齐实测差距的 40% / 70% / 100%，每一项都有上限：
   - 亮度：中位 L\* 每档最多移动 ±15；
   - 对比度：5%–95% 跨度最多缩放到 0.8–1.25 倍；
   - 饱和度：C\* 最多缩放到 0.8–1.35 倍。
   
   上限是初始值，由 PoC 校准。
3. **场景差异守卫**：两张图明暗或饱和度差得过大时（例如中位 L\* 相差 > 25，初始值），说明它们大概率不是同一系列。此时：
   - 明暗、饱和度两项按"轻"档封顶；
   - 提示"两张图场景差异较大，只做有限的明暗与饱和度对齐"；
   - 白的对齐不受影响。
4. **硬保护**（任何一档都必须满足）：
   - 尺寸、方向、Alpha 不变；
   - 高光和暗部的裁切增量 ≤ 0.5%，不出现大面积过曝或死黑；
   - 不新增色带；
   - 肤色沿用 S64 的保护规则，色相偏移 ≤ 10°，饱和度不超过安全范围；
   - 文字和 Logo 形状不变。
5. **建议与提示**：
   - 摘要说明三项各自的变化方向，例如"结果会变亮、更鲜艳、变暖"；
   - 沿用 S66-C 的建议规则。参考图的白偏色、目标图本身正常时，仍建议"原图"，但各档可选；
   - 这一项另需决定：当明暗或饱和度差距明显时，建议档位怎么定（见 Q1）。
6. **技术边界**：本地确定性算法；在 S66 已有的白对齐之上，增加全局色调曲线和饱和度缩放；不重绘、不联网、不使用生成模型。

### 3. 与现有成果的关系

- S66（含 S66-C）的白对齐是新方法的第一步。新方法在明暗与饱和度两项不动时，必须与 S66 的结果逐像素一致。
- 挑档校色、自动校色、旧 `reference-run` 均不变。
- 先由 PoC 证明有价值，再按 S64、S66 的方式另开集成阶段。PoC 不进入正式运行链。

### 4. 需要负责人裁定的问题

- **Q1 建议档位**：明暗或饱和度差距明显时，系统建议哪一档？
  - 建议：沿用"中"档，但触发场景差异守卫时建议"轻"档。
- **Q2 适用场景**：是否需要提醒用户"参考图最好是同一系列、同一场景"？
  - 建议：保留现有提示，并在场景差异守卫触发时加强提示。

### 4. 不可破坏边界

- **必须保留**：正式颜色链、S64 与 S66 的冻结成果（包括 S66-C 的工作区改动）、API、页面、Settings、正式目录、版本号、其他功能。

### 5. 结果门禁（数值为初始建议，执行方不得自行放宽）

1. **G 组更接近标准答案**：
   - 强档与干净原图之间的平均 ΔE00，比加工后的目标图下降 ≥ 50%；
   - 亮度、对比度、饱和度三项指标的差距各缩小 ≥ 60%；
   - 轻 → 中 → 强单调递增；没有任何一组比原来离标准答案更远。
2. **同图不变**：参考图与目标图相同时，强档变化的平均 ΔE00 ≤ 0.5。
3. **兼容 S66**：关闭明暗和饱和度两项后，输出与 S66 同档逐像素一致。
4. **色相不变**：中性区以外的像素，色相角平均变化 ≤ 3°（白对齐带来的变化单独计算）。
5. **安全**：裁切增量 ≤ 0.5%；肤色色相偏移 ≤ 10°；尺寸、Alpha 不变；不新增色带。
6. **X 组守卫生效**：场景差异守卫被触发，明暗与饱和度按轻档封顶，并给出提示。
7. **耗时**：比 S66 预览多出的时间 ≤ 1 秒（空闲时）。
8. **复核包**：每组一张"目标 / 参考 / 轻 / 中 / 强"并排图；附 `HUMAN_REVIEW.md` 逐组打分表，内容包括"是否更像参考图""能否直接使用""是否有伤害"。
