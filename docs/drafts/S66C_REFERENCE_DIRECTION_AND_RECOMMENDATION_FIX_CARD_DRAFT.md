## 1. 问题来源（负责人 2026-10-29 实测）

负责人用一张会议室照片作目标图、一张白花 AI 图（`2.png`）作参考图。原图颜色正常，校色后整体偏暖。

只读诊断结果：

| 项目 | 数值 |
|---|---|
| 原图白墙、桌面、灰区的 b\* | −1 ～ +3，基本中性 |
| 白花图自身的"白" | b\* ≈ +14.5，偏黄绿 |
| 用白花图校色后（中档）的灰区 b\* | +10 ～ +12，明显偏黄 |
| 页面提示 | "目标图比参考图偏蓝、偏品红"，系统建议"中"档 |
| 单图测量（S64）对原图的判断 | NO_CAST，建议原图（判断正确） |

算法本身没有出错：它按设计把目标图的白拉向参考图的白。问题出在三处：
1. 提示只说了"目标与参考的相对差"，用户会理解为"原图偏色、需要修"；
2. 没有提示参考图自己的白不是中性；
3. 目标图本身已经正常时，仍然建议"中"档。

## 2. 本阶段唯一目标
