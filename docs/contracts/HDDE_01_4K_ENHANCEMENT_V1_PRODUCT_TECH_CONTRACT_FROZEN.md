# HDDE｜01｜4K高清增强 V1 产品与技术合同

## 1. 合同性质

本合同是4K高清增强V1的产品目标、高清核心职责、技术边界、硬件策略、真实性红线、当前技术状态和后续完成门禁的权威冻结文件。

本次冻结不代表4K高清增强技术已经完成，不代表任何研究候选已经进入正式产品，也不授权修改正式1080P/4K处理链、产品接口、UI、Settings或正式输出合同。没有被真实结果证明的能力继续保持`NOT_PROVEN`。

本合同不预设后续使用的具体模型、模型家族、权重、组合方式、参数、评分阈值或性能阈值。技术选择只由真实商业图片结果、真实性、资源成本和交付价值决定。

## 2. 产品定位

4K高清增强不是把像素尺寸放大到4K，而是面向真实商业交付，同时建立以下四项价值：

```text
4K高清增强价值 = 真实画质增益 + 真实性 + 文件体积 + 桌面端性能
```

- `真实画质增益`：恢复可被图像证据支持的结构、边缘、纹理和可读信息，不把插值尺寸、锐化、噪点或生成纹理当作增益。
- `真实性`：人物、文字、Logo、产品、材质、颜色、几何与透明通道保持原图事实。
- `文件体积`：输出体积必须与有效画质收益匹配；无意义高频造成的体积膨胀属于负收益。
- `桌面端性能`：处理时间、内存/显存、设备压力、失败与回退必须具备Windows、macOS和HarmonyOS PC桌面产品的现实可执行性；当前验证优先覆盖Windows。

任何单项成立都不能单独宣称4K高清增强成功。尺寸达到4K、文件生成成功、自动指标提高或观感更锐均不等于V1成立。

## 3. HDDE高清画质核心V1职责

HDDE高清画质核心V1必须完整承担以下职责，后续实现不得因模型能力或工程便利删减：

1. `退化判断`：从真实输入判断压缩伪影、噪声、模糊、无意义高频、分辨率与内容风险；不得为了启用技术而假定退化存在。
2. `安全恢复`：只治理证据明确且可逆风险可控的退化；无增益、降低细节或改变结构时应退出或回退。
3. `真实有效信息恢复`：恢复能由原图、GT或可信结构证据支持的信息；锐化轮廓、随机纹理和生成性美化不得计入。
4. `中文/Logo保护`：保持笔画、字形、数字、间距、标识轮廓与品牌事实，不得补造或改写。
5. `人物保护`：保持身份、五官、年龄特征、皮肤与头发事实，不得美容、换脸或制造假发丝。
6. `产品/材质保护`：保持产品结构、比例、接口、边界以及金属、玻璃、织物等材质事实，不得重解释设计。
7. `Alpha源通道保护`：Alpha默认采用已经证明安全的源通道旁路；任何替代方案必须重新证明逐像素透明结构安全。
8. `假高频控制`：识别并抑制光晕、双边轮廓、噪点、伪笔画、塑料感和不可证实微纹理，并允许对应技术积木退出。
9. `4K重建`：从原图直接完成保持比例的4K重建，不串联1080P结果，不裁切、不拉伸、不补边；重建必须服从真实性，而非只服从目标尺寸。
10. `交付编码`：在统一合理编码条件下控制格式、色彩、Alpha、文件体积与可解码性，使输出具备真实交付价值。

高清核心负责统一组织以上能力，但不等于建设通用AI框架、复杂模型平台或自动视觉裁判系统。技术积木允许动态组合，只有被当前图片证据触发且确有价值的积木才能执行。

## 4. 硬件策略

产品只向用户提供一个统一能力：`4K高清增强`。

内部同时保留两类运行路径：

- `CPU / Intel通用运行路径`：承担不依赖NVIDIA CUDA的基本可用能力和安全回退，确保CUDA不是基本使用门槛。
- `NVIDIA GPU高性能增强路径`：在设备、驱动和隔离运行环境真实可用时承担更高性能或更高能力上限的增强处理。

两类路径必须遵守同一产品目标、真实性红线、输出语义和失败合同。NVIDIA路径不可用、资源不足或运行失败时，系统只能回退到已经证明安全且设备可执行的能力；不得静默降级后仍宣称同等画质增强，也不得以临时目录、假结果或未证明模型制造成功。

本合同不冻结具体设备路由、模型、推理后端、参数、资源阈值或性能阈值，这些内容必须在后续真实验证中形成。

- `RESEARCH`：存在潜力或对照价值，但画质、环境、性能或产品可行性尚未证明。
- `NOT_PROVEN`：不得进入已完成、已支持、已冻结能力或用户宣传口径。

## 6. 真实性红线

任何候选、技术积木、组合或硬件路径只要触发以下任一项，就不能被认定为技术突破：

- 改变人物身份、五官、脸型、年龄特征或人物真实结构；
- 改写、补造或损坏中文笔画、数字、小字和Logo；
- 改变产品结构、接口、边界、比例、几何或品牌设计；
- 重解释金属、玻璃、织物、皮肤、头发、建筑等真实材质与细节；
- 制造无法由原图、GT或可信证据支持的纹理、发丝、锐化边缘或随机高频；
- 产生光晕、双边轮廓、塑料感、噪点放大、色偏或结构漂移；
- 破坏Alpha通道、透明边缘、半透明层次或源图可恢复信息；
- 以更锐、更漂亮、文件更大、指标更高或尺寸正确替代真实信息增益证据。

自动指标只允许作为辅助证据，不能替代原尺寸人工判断、关键局部检查、GT核对和真实商业交付判断。

## 7. V1后续完整完成门禁

以下七道门禁必须全部完成且不得删减。前一门禁没有真实证据时，不得把后一阶段的工程完成包装成V1成功。

### Gate 1｜核心真实画质突破

- 在代表性真实Crop和必要GT降采样样本上证明相对当前安全基线及现有研究对照的新增真实有效信息。
- 增益必须通过原尺寸、100%/必要时200%局部人工检查，并通过人物、中文、Logo、产品、材质和Alpha真实性检查。
- 模型、参数和判断阈值由证据形成，不在本合同中预设。

完成条件：`REAL_INFORMATION_GAIN=PROVEN`且`PIXEL_FIDELITY=PASS`；否则高清核心继续保持`NOT_PROVEN`。

### Gate 2｜高清技术积木组合

- 建立退化判断、安全恢复、有效信息恢复、假高频控制、Alpha保护、4K重建与交付编码的最小动态组合。
- 每块积木必须得到`KEEP / DROP / RESEARCH`结论，并记录实际增益与副作用。
- 不允许无条件串联全部处理，也不允许用组合复杂度替代画质收益。

完成条件：被保留积木各自有独立价值，组合结果优于单块核心且没有真实性回退。

### Gate 3｜4K正式单图闭环

- 在Gate 1和Gate 2成立后，才允许接入正式单图链路。
- 必须从原图直接完成输入校验、处理、结果验证、4K输出、失败阻断与可追溯状态，不覆盖原图。
- 复用现有Task/Result/Delivery、处理中心和正式目录合同，不建设平行系统，不改变既有1080P语义。

完成条件：真实单图路径可重复完成，输出存在、可解码、尺寸/比例/格式/Alpha正确，失败不会产生孤儿结果或假成功。

### Gate 4｜CPU/Intel/NVIDIA适配与安全回退

- 完成CPU/Intel通用路径与NVIDIA高性能路径的真实设备验证。
- 明确能力差异、资源需求、失败原因和回退事实；回退后必须如实表达实际执行能力。
- 任何设备路径都必须遵守同一真实性红线和正式数据保护合同。

完成条件：无NVIDIA设备仍有已证明安全的可用路径；NVIDIA路径成功时提供真实增强或性能价值，失败时安全回退且不误报。

### Gate 5｜性能与文件体积收口

- 在真实4K样本上记录端到端时间、CPU/GPU/内存/显存压力、输出体积和统一编码条件。
- 判断同等观感下的体积、同等体积下的有效画质，以及无意义高频造成的编码膨胀。
- 性能和体积门槛由真实桌面体验与商业交付形成，不在本阶段写死。

完成条件：处理成本、失败率和文件体积与画质收益匹配，具备桌面端现实使用价值。

### Gate 6｜真实商业样本验收

- 覆盖AI商业视觉、商务人物、产品/材质、中文/PPT/图形、建筑/空间、JPEG或轻模糊真实图片以及Alpha样本。
- 每张保留原尺寸结果、整图对照和关键局部，最终结论由真实人工画质判断形成。
- 自动指标、自动截图或单一示例不得替代整体验收。

完成条件：代表性商业样本证明稳定有效增益，没有系统性真实性风险，并具有真实交付价值。

### Gate 7｜V1最终冻结

- Gate 1—6全部通过，高清核心、技术积木、硬件路径、正式单图闭环、编码、性能、文件体积和商业样本均有可审计证据。
- 同步冻结产品能力边界、正式技术状态、失败/回退语义、最低回归验证和用户可见真实口径。
- 原图、Settings、正式目录、1080P/既有4K成果、颜色校正和其他并行成果保持安全。

完成条件：`HDDE_HIGH_DEFINITION_CORE_V1=PROVEN_AND_FROZEN`。任何门禁未通过时不得使用此状态。
